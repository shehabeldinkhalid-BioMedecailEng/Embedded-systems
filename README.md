# Embedded Systems Diploma — Course Outline

A structured curriculum (164 hours) from AMIT Learning covering embedded
systems development from fundamentals to industry-standard frameworks.

## Roadmap

1. **Introduction to Embedded Systems**
2. **C Programming & Data Structures** — user-defined types, control flow,
   functions, pointers, arrays, strings, algorithms
3. **Embedded Systems Tooling**
4. **Interfacing with AVR Microcontroller** — computer architecture, DIO,
   layered architecture, LCD/keypad/seven-segment display, interrupts,
   ADC, timers (PWM/ICU/WDT), UART/SPI/I2C, EEPROM
5. **Automotive Bus Technology** — CAN & LIN
6. **Real-Time Operating Systems (RTOS)** — concepts + FreeRTOS
7. **AUTOSAR Standards**

Optional free module: Testing & Validation (ISTQB Foundations, 16 hrs).

## Hardware
Includes a free AMIT development kit (AVR-based, ARM Blue Pill / Raspberry
Pi compatible) with TTL, Bluetooth module, DC motor, and servo motor.

## Capstone
Real-life graduation project (e.g., ultrasonic-sensor robot car).
